# Read this before doing anything else

This project has no human development team — it is built entirely by Claude Code agents across sessions. Before writing or changing any code, read `docs/AGENT_LOG.md` in full: it holds the cross-session handoff, standing engineering guardrails, and current status. At the end of your session, update it per its own protocol section. Do not skip this because the task looks small — the log is the only memory this project has.

See `docs/MVP_ARCHITECTURE.md` for the target architecture and build plan.
