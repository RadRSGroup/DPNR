# Agents Directory

This folder holds specifications for each specialized sub-agent defined in the PRD. Each agent should read their spec, then execute only the current task from `/tasks/todo.md`.

- `project-coordinator.md` — orchestrates development, prevents scope drift
- `frontend-developer.md` — Next.js 14 + Tailwind + shadcn/ui + R3F (landing-only)
- `backend-developer.md` — Next.js API routes, Prisma/Postgres, S3, Zod, Iron Session
- `auth-specialist.md` — Cognito + Amplify, GDPR checklist
- `payment-specialist.md` — Stripe Checkout integration
- `3d-specialist.md` — Landing hero 3D with R3F/Drei + mobile fallback
- `testing-engineer.md` — Minimal but essential automated tests
- `deployment-engineer.md` — Terraform + deployment steps

Refer to `dpnr-course-prd.md` as the single source of truth.
