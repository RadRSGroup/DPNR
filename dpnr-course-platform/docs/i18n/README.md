# i18n Docs

This folder contains language resources used for localization.

- `hebrew-lexicon.md`: Human‑readable glossary mapping common product terms to Hebrew, including usage notes and style guidance.
- `messages.he.json`: Seed translation file for UI strings (landing + header). Use this as a starting point for `next-intl` or your preferred i18n library.

Conventions:
- Prefer clear Modern Hebrew, masculine generic when neutrality is acceptable; call out gendered cases explicitly.
- Keep strings concise; avoid transliteration where a common Hebrew term exists.
- RTL: verify visual order and punctuation for inline English terms and numbers.
