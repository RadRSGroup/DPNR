## Style & Usage Notes
- Numerals: prefer European digits (0–9) in technical and prices; add currency symbol before number (₪100).
- Punctuation: keep RTL direction; inline English terms may require LRM/‌RLM in edge cases.
- Gender: use masculine generic where neutral; if addressing directly, consider dual forms or rephrase.
- Tone: concise, practical, non‑marketing.

## RTL Tips
- Use `dir="rtl"` for Hebrew pages; verify button order still reads logically.
- For paired CTAs, primary on the right in RTL by default.
