the Library. These are stopgaps and should all be replaced.

Match the existing sets: same size range as the others (square ~1254×1254, portrait

`docs/reference-screens/theme_and_section_photos/<folder>/` using the topic name as
the file name (e.g. `Needs & Values/Values.png`). The code side is in
`apps/web/src/lib/library/topic-images.ts` (`PLACEHOLDER_TOPIC_PHOTOS`).
